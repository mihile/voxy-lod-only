# 검증과 지원 범위

0.9.0의 다중 플레이어 성능 변경과 격리 비교는
[별도 검증 기록](../verification/FLIGHT_PERFORMANCE.md)을 참고하세요.
0.9.0 정식 패키징은 Java 17 대상 빌드와 단위 검사 54개를 다시 확인합니다.
VoxyServer port.2는 단위 검사 19개 대상입니다. 과거 격리 실행 결과는 당시 후보 JAR의
기록이며, 최종 정식 JAR로 전체 모드팩 비행 비교를 다시 실행한 결과는 아닙니다.
Integrated Villages의 잘못된 주민 풀 참조 6개는 원본 리소스 조사와 회귀 검사로 보정했습니다.

아래는 기존 0.8 공개 배포 시점의 기록입니다.

Minecraft 1.20.1 전용 Fabric 서버를 대상으로 합니다. 기본 Noise/Flat 지형 생성기를
지원하며 다른 종류의 커스텀 생성기는 거부합니다. 모드 지형 생성 방식에 따라
실제 방문 후의 지형과 LOD 미리보기가 완전히 같지는 않을 수 있습니다.

## 확인한 동작

- Java 17 대상 빌드 및 JUnit 검사 29개.
- 별도 테스트 월드에서 오버월드·네더 생성, 취소, 재접속, 설정 재적용, 완료 기록 재사용.
- 배포 직전 공개 Voxy port.8 / VoxyServer port.1 조합으로 설정 재적용 검사 통과:
  수동 작업 유지, 잘못된 설정 거부, 생성·완료 기록 재사용, 재시작 후 설정 보존.
- 선택한 원거리 위치에 일반 terrain/entity/POI 청크 파일을 저장하지 않음.
- Prominence 모드팩에서 구조물 템플릿 806개 대조 및 오버월드 블록·바이옴·조명 일치 검사.
- 실제 클라이언트가 LOD Only 없이 원거리 데이터를 수신하고 Voxy 렌더러로 처리함.
- 실제 운영 환경에서 자동 반경 128의 작업 완료, 클라이언트 수신 기록 증가,
  Voxy 렌더링을 껐다 켰을 때 원거리 지형이 사라졌다 다시 나타나는 동작.

빌드에 사용하는 공개 의존 JAR은 [빌드 문서](BUILD.md)의 해시를 기준으로 합니다.
전체 모드팩/클라이언트 검사는 Voxy port.8과 로컬 설치된 VoxyServer port.1을 사용했습니다.
그 VoxyServer 복사본의 SHA-256은
`a4c7947b19b58a1cabe5803723659954d2dc8c74e971cc7d0ba4274dd17215c2`이며,
공개 port.1 릴리스 JAR과 동일한 파일은 아닙니다. 실행별 의존성을 혼동하지 마세요.

## 알려진 제한

- BetterNether의 일부 생성은 시드와 무관한 난수를 사용하므로 반복 생성도 달라집니다.
  네더 전체가 일반 생성과 비트 단위로 일치한다고 보장하지 않습니다.
- 한 클라이언트 검증에서 VoxyServer의 해시 보조 파일 교체 중 Windows
  `AccessDeniedException`이 발생했습니다. LOD 수신·렌더링 기능은 확인했지만
  해당 실행의 해시 인덱스 최종 저장은 불완전했습니다. 별도 VoxyServer 문제로 남아 있습니다.
- 모든 모드팩·시드·바이옴·셰이더 조합을 검증한 것은 아닙니다.
  FPS 개선이나 일정한 생성 속도를 보장하지 않습니다.
